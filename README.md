# Клиника: управленческий дашборд (прототип)

Отдельный проект, не часть табеля. Папка лежит вне `public/`, поэтому на сайт табеля не деплоится;
перед запуском в работу вынести в свой репозиторий и свой Supabase-проект.

Задача заказчицы: в одном месте видеть реальную выручку, ДДС, расходы, прибыль, прогноз и
мощность клиники (загрузка врачей, операционной, диагностики, потенциал выручки).

## Этап 1 (сделано): прототип на демо-данных
`public/index.html` открывается без сервера и без БД — данные генерируются в `public/data.js`
(демо, цифры выдуманные). Показывает: KPI, выручка/расходы/прибыль по месяцам, ДДС,
отделения, врачи, мощность и потенциал выручки, простой прогноз.

Запуск локально: `cd public && python3 -m http.server 8080`.

## Дальше
1. Выяснить у заказчицы источники данных (1С, МИС, таблицы) и справочник статей.
2. Создать Supabase-проект, выполнить `schema.sql`, заменить `loadData()` в `public/data.js`.
3. Импорт CSV/Excel из бухгалтерии и МИС.
4. Прогноз с сезонностью, интеграции.

Персональные данные пациентов не хранить (закон о ПДн, медтайна) — только агрегаты.

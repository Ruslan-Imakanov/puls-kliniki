# Пульс клиники

Управленческий учёт для частной клиники: деньги, прибыль, долги, мощность, врачи, услуги, маркетинг и склад в одном месте.
Отдельный проект, не часть табеля. Папка лежит вне `public/` табеля, поэтому на его сайт не деплоится.
Перед запуском у клиента вынести в свой репозиторий и свой Supabase-проект.

Требования, по которым сделан продукт: [`docs/REQUIREMENTS.md`](docs/REQUIREMENTS.md).

**Демо в интернете:** https://puls-kliniki.imakanovr.workers.dev — Cloudflare Workers (статические файлы), выложено вручную
загрузкой содержимого `public/` через панель Cloudflare. Обновить = загрузить папку заново («Новое развертывание»).
На Netlify (команда Qadam) есть пустой проект `puls-kliniki` — не использовался, т. к. у команды закончились кредиты.
Обучающий ролик и его сборка — в [`video/`](video/README.md).

## Разделы
| Раздел | Что показывает |
|---|---|
| Обзор | Главные цифры за период, график с прогнозом, сигналы «требует внимания» (кассовый разрыв, просроченные долги, низкая загрузка, неявки, низкая маржа, отклонения от плана, склад) |
| Операции | Журнал доходов, расходов, переводов: поиск, фильтры, добавление (клавиша N), копирование в Excel |
| Прибыли и убытки | ОПиУ по методу начисления: выручка → возвраты и отказы → маржинальная прибыль → EBITDA → амортизация → налоги → чистая прибыль; раскрытие по статьям, переход к операциям из ячейки |
| Движение денег | ДДС по дате оплаты (операционная, инвестиционная, финансовая деятельность), остатки по счетам, прогноз остатка на 3 месяца |
| План-факт | Бюджет по статьям с вводом в таблице, отклонения, точка безубыточности, запас прочности |
| Долги | Дебиторка (ДМС, фонд, рассрочки) и кредиторка: старение долгов, оборачиваемость, отметка оплаты (в т.ч. частичной), отказы страховой |
| Мощность | Загрузка врачей, кабинетов, оборудования; потенциал выручки до целевой загрузки; узкие места; тепловая карта; сценарий «что если»; ввод часов |
| Врачи и зарплата | Выручка, выручка за час, средний чек, повторные, неявки, кросс-выручка; расчёт зарплаты по схеме (оклад, процент, оклад + процент, процент от маржи) и начисление |
| Услуги | Себестоимость (материалы по нормам, врач, эквайринг, накладные), маржа, маржа за час, ABC-анализ, ввод объёмов продаж |
| Маркетинг | Воронка по каналам: обращения → записи → визиты → новые пациенты; CPL, CAC, ROMI, LTV, LTV/CAC |
| Склад | Остатки, партии и сроки годности (FEFO), приход, расход, списание по нормам услуг |
| Загрузка из Excel | Импорт XLSX/CSV (в т.ч. Windows-1251 из 1С): автоподбор колонок, проверка, защита от дублей, создание недостающих справочников |
| Справочники | Статьи (группа определяет место в ОПиУ/ДДС), отделения, врачи, ресурсы, счета, контрагенты, каналы, номенклатура |
| Настройки | Параметры расчётов, резервная копия, демо/чистый лист, журнал изменений |

## Как устроено
- Чистые HTML/CSS/JS без сборки, ES-модули (`public/js`). Запуск локально: `cd public && python3 -m http.server 8080`.
- Данные сейчас хранятся в браузере (`localStorage`, `js/store.js`). При первом запуске загружаются демо-данные
  (выдуманная многопрофильная клиника за 12 месяцев) — их можно заменить на чистый лист в «Настройках».
- Все расчёты — чистые функции в `js/calc.js`. Ключевое правило: у операции две даты — `date` (оказание услуги / начисление → ОПиУ)
  и `paid` (движение денег → ДДС, пусто = долг).
- Один файл для показа/публикации: `python3 tools/build_artifact.py out.html [--standalone]`.

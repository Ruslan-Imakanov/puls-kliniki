# Обучающий ролик «Пульс клиники»

Ролик собирается из настоящей программы: Playwright открывает её с демо-данными, режиссёрский слой
(`director.js`) покадрово выставляет субтитры, подсветку, курсор, карточки с формулами и слайды,
ffmpeg кодирует 1920×1080, 30 кадров/с и накладывает озвучку.

| Файл | Что внутри |
|---|---|
| `script.mjs` | Сценарий: 32 сцены, дикторский текст и действия на экране (привязаны к номеру фразы) |
| `tts.mjs` | Как диктор произносит аббревиатуры (EBITDA → «ибитда» и т. п.) |
| `audio/*.mp3` | Озвучка по сценам (ElevenLabs, голос «Pavel — Warm Conversational Narrator») |
| `director.js` | Слой поверх программы: всё считается от времени t, без CSS-анимаций. «Камера» сама прокручивает страницу, окно или широкую таблицу, чтобы подсвеченный элемент оказался под шапкой и над субтитрами |
| `render.mjs` | Таймлайн по паузам в аудио, рендер кадров, звук, субтитры SRT |
| `sample-ops.csv` | Пример выгрузки для сцены импорта |

## Пересобрать
Нужны Node 18+, Playwright с Chromium и ffmpeg. Если Playwright стоит глобально или браузер лежит не там, где
его ищет Playwright: `PLAYWRIGHT_MODULE=/путь/к/playwright/index.mjs`, `CHROMIUM_PATH=/путь/к/chrome`.
```
python3 ../tools/build_artifact.py out/pulse_local.html --standalone
node render.mjs --check                 # все селекторы находятся
node render.mjs --audit                 # каждая подсветка и курсор целиком в кадре (должно быть 0 замечаний)
node render.mjs --stills 6,134,410      # контрольные кадры в out/
node render.mjs --out out/pulse-clinic.mp4   # полный ролик + .srt (≈ реальное время)
```
Если меняется текст сцены — переозвучить только эту сцену и положить mp3 с тем же именем в `audio/`.
Готовые видео (`out/`) в репозиторий не кладутся.
